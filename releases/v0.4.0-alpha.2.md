# Memory Lab Study v0.4.0-alpha.2

Preserves the current development milestone, including patch save/load, DAW
automation checks and the growing hardware-inspired instrument evidence notes.
The plugin still reports 0.4.0. Existing synthesis and parameter IDs are unchanged.

## Added since alpha.1

- SAVE/LOAD buttons with native dialogs and separate `.mlpatch` files storing
  all 35 synthesis, envelope, output and arpeggiator controls.
- Complete patch validation before applying values; malformed, incomplete,
  duplicate, unknown and out-of-range controls are rejected. Saves use temporary
  files before replacing the destination.
- Automation parameter/order, gesture, editor-following and recall checks.
- An isolated Windows accessibility lifecycle regression with eight editor
  destruction/reference-release cycles.
- Reusable hardware-to-VST workflow notes and creator-interview evidence,
  distinguishing prototype generations, stated features and remaining unknowns.

## Verification

- All four CTest checks passed: wrapper_smoke, automation_foundation,
  patch_files and uia_editor_lifecycle.
- Actual VST3 scan, instrument classification, instantiation, MIDI/arp audio,
  state roundtrip, all-off/release silence and reload at 44.1 kHz passed.
- Editor snapshot/attachment checks passed; compact SAVE/LOAD layout inspected.
- FL Studio recognized cutoff as last tweaked and played an edited automation
  clip in earlier host testing. Full recording/undo/project recall is not yet
  verified, nor are the new native patch dialogs inside FL Studio.

## Known limits and preserved behavior

The captured FL Studio reload crash involves UI Automation provider cleanup;
provider ownership remains unresolved. Active investigation is parked until a
recurrence. Passing the isolated test does not validate VST3 unloading or FL reload.
Evidence is retained locally; memory dumps are not release assets.

The approved sound engine and all 35 parameter IDs remain unchanged. Envelope
stages latch at note-on. DAW automation may override loaded patch controls.
Existing alpha.1 arp limitations still apply: BPM following rather than PPQ-grid
alignment, no latch/swing/random/step sequencer or generated MIDI output.
This remains a partial original instrument, not a measured Relic emulation.

## Distribution

Source-only prerelease, without binary assets. The installed Windows plugin is
unchanged and does not yet include the development build's patch buttons.
Build instructions and pinned JUCE dependency are documented in plugin/README.md
and plugin/dependency.json. Binary distribution licensing remains to be selected.
The guarded local update script targets the earlier 0.3-to-0.4 update and is not
an installer for this snapshot. The alpha.1 tag remains unchanged.
