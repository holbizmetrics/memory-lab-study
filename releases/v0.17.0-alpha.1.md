# Memory Lab Study v0.17.0-alpha.1

MOTION / LFO 1-4 now offers AMP DEPTH for independent per-voice tremolo, using
each source's existing rate, shape and clock. Depth zero bypasses exactly;
absolute depth one attenuates between zero and full level, negative reverses
phase. Multiple sources multiply their gains after the filter and before voice
drive. ENVELOPES / ROUTES adds amplitude/filter envelope pitch depths and
ENV 3/4 pulse-width depths, alongside convenient existing ENV 3/4 destinations.
Source stages remain on their original pages. This is an explicit expansion,
not a general modulation matrix or a complete hardware routing model.

SOUNDS adds optional Auto-load on selection, off by default. A newly selected
sound loads through the existing preset path; categories, opening the panel and
enabling the checkbox never load anything. Output stays as set, both drives
load bypassed, and UNDO LOAD restores the full sound before the most recent
load. The option persists locally alongside the patch-folder preference, not
inside sounds or DAW state. LOAD SOUND remains available. Other open instances
need not follow preference changes live; save edits before auditioning.

Compatibility: eight depths append after the previous 92 stable IDs, 100 sound
parameters total. All new depths default zero and are smoothed. Patch schema 12
and host state 14 store them; schemas 1-11 and legacy host states restore missing
routes inactive. INIT and starter sounds reset new routes off; Dice protects
them. Both old default audio and active 0.16 envelopes are preserved exactly in
actual-module comparison fixtures. The previous LFO 1 Recovery duplicate and
LFO 2-4 Output duplicates on source pages give way to AMP DEPTH; those existing
parameters remain available elsewhere, with unchanged host IDs/order.

Validation: Windows VST3/standalone build; 14/14 plugin checks (100.99 s),
6/6 native checks (36.81 s). Eight routes, both signs, four sample rates,
combined sources, block/release parity, 100 IDs/bindings/gestures, old/new
patch and host recall, Dice protection, 352 passive page changes and isolated
editor lifecycle passed. Private-file tests cover auto-load default off,
selection-only activation, passive toggles/categories/opening, output/drives,
Undo and persistent preference/folder coexistence. Nineteen actual VST3 captures
pass, peak 0.371115 at fixture output. Default, clocked, active 0.16 envelopes
and the local saved two-LFO sound render byte-identically to preserved captures.
Actual VST3 scan/load/audio/arp/state/release/reload passed. PE/plugin versions
report 0.17.0; normal/compact new UI captures inspected.

Holger confirmed 0.16 envelope listening and patch/FL-restart project recall.
New 0.17 destinations and auto-load musical/UI confirmation remain pending.
Complete FL automation/undo, all routing extremes and realtime xrun testing
remain open. Existing project instances may expose a shorter parameter table;
use a fresh instance for manifest inspection and never shift mismatched indices.
This is an original Relic-inspired instrument; oscillator/filter expansion,
four-part architecture and hardware matching remain further milestones.

Source-only prerelease with no binary assets until distribution licensing is
selected. Installed build status is separate from source publication.
