# Memory Lab Study v0.21.0-alpha.1

MOTION / CLOCK 1–4 adds a per-part POLARITY control: BIPOLAR (-1…+1) or
UNIPOLAR (0…1). Pitch, pulse-width and cutoff routes can move one-sided around
their base setting, using any existing shape. Positive/negative depths select
the direction. Preview and BI/UNI readout follow the selected source.
Polarity transitions smooth without resetting phase. AMP DEPTH keeps its full
attenuation cycle in both modes; see plugin/LFO-POLARITY.md for that policy.

Compatibility: 16 controls append after all previous 409, totaling 425.
Existing IDs/order/ranges and shape choices remain. Schema 16 / state 18 migrate
older sounds to bipolar defaults. Starter sounds, INIT and part copying include
polarity; Dice preserves it. The approved old signal path is unchanged.

Validation: 19/19 plugin CTest and 9/9 native CTest pass. Four-rate
multipart held-note edits, append-only parameter order, legacy migration,
patch/host recall, selected-part copy/starter behavior and UI bindings pass.
Thirty-seven actual 0.20 VST3 recordings remain byte-identical; eight actual
module polarity examples produce the intended differences. The approved native
reference phrase remains exact. Actual module scan/load/MIDI/arp/state/release/
reload passes. Normal and compact CLOCK previews inspected.
Musical listening approval of the new polarity controls is pending. Exact
hardware phase/control-law matching, modulator-to-modulator routing, MPE and
switchable extended low-pass bandwidth remain separate stages. No claim of
complete Relic emulation. Full FL recording/undo and realtime/aliasing review
remain open.

Source-only prerelease without binary assets pending distribution licensing.
Installation requires FL/standalone closed and a verified 0.20 backup.
