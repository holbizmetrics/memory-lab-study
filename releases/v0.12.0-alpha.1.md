# Memory Lab Study v0.12.0-alpha.1

VOICE gains SOUND / EXPRESSION subpages. Three new controls add filter keyboard
tracking around MIDI 60 / C4 and independent amplitude/filter-envelope velocity
sensitivities. KEY TRACK at 100% doubles cutoff per octave up and halves it per
octave down. AMP VELOCITY and FILTER ENV VEL at 100% retain their original linear
velocity responses; 0% removes velocity dependence from the corresponding source
gain or envelope amount. Filter-envelope amount must be nonzero to hear its
velocity sensitivity. Existing pressure, envelope amount, cutoff, resonance and
output controls are available alongside normalized response previews.

Compatibility: existing 46 host IDs/order are unchanged. keyTrack, ampVelocity
and filterVelocity append at indices 46–48. Neutral defaults are 0%, 100%, 100%.
New schema-8 patch files store all 49 controls and require 0.12 or later. Schemas
1–7 and old host states restore neutral expression defaults, including after
expression edits in the same instance. INIT restores them; dice rolls preserve
all three expression controls. The optional dice drive-bypass checkbox remains.

Validation: Windows VST3/standalone built; all nine plugin CTest checks passed.
Expression checks cover C4 reference, octave/half-tracking cutoff ratios,
independent amplitude and filter-envelope velocity responses, oscillator/noise
gain, four sample rates (44.1/48/96/192 kHz), note/cutoff extremes, exact block
partition parity and host migration. Existing patch/automation/clock/randomizer/
lifecycle tests pass, including 49-control roundtrip, stable IDs/gestures, 192
page switches without parameter writes and protected nondefault expression
settings during dice rolls. Actual VST3 scan/load/MIDI/arp/state/release/reload
passed. Default audio and a migrated schema-7 clocked fixture are byte-identical
to prior verified captures. Normal/compact response previews were inspected.

Listening status: Holger explicitly chose to continue development and batch-test
0.12 with the pending 0.11 alpha-2 drive-bypass interaction. Neither that choice
nor these technical checks establish musical approval of the new controls.
The combined listening recipe is in plugin/EXPRESSION.md. Original 0.11 dice
sounds and 0.10 clock movement had prior user confirmation.

Limits: note-number tracking, not pitch-bend tracking; cutoff clamps still apply.
The new controls use existing-style smoothing, and sensitivity previews describe
source/envelope scaling, not output loudness through nonlinear drive. Full source
gain at zero amp sensitivity may be louder than a soft note previously was.
This is not MPE or a full Relic modulation architecture. Envelopes retain existing
note-on stage latching. New patches are not readable by earlier builds. Full FL
automation/undo/project-reload and live folder-persistence checks remain open.
Local updates require closed hosts and verified backup. Source-only prerelease,
no binary assets, pending distribution licensing.
