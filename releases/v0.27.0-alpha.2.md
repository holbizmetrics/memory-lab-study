# Memory Lab Study v0.27.0-alpha.2

**VOICE → EXPRESSION → MPE PRESSURE** routes lower-zone member
aftertouch to filter cutoff for the selected part. **MPE PITCH** on **PARTS**
enables the route. Depth is signed, from −2 to +2 octaves, and applies to
the note's entire unison stack. Sustained and released notes retain their
pressure after key-up. A new note on an idle member channel starts at zero
unless pressure arrives before note-on.

Four parameters append to the existing 514, for 518 total controls.
Patches and projects save the new depths with schema 24 and host state 26.
Earlier saves keep their existing **PRESSURE** depth and default to zero
MPE pressure depth. The existing **PRESSURE** route keeps its behavior.

The Windows VST3 and standalone built successfully. All 27 plug-in and
13 native checks passed. The built VST3 passed signed pressure, member
isolation, unison, sustain, channel reuse, and the prior pitch checks.
All 42 prior captures and Two Lanterns matched exactly in both channels.
The native reference phrase stayed exact.

Holger confirmed independent pitch and project recall on alpha.1, and
heard the existing pressure route using two internal MIDI Out channels
in FL. Musical listening and recall for the dedicated route are pending.
Per-note timbre remains planned. This is a source-only prerelease.
