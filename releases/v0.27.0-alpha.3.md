# Memory Lab Study v0.27.0-alpha.3

**FILTER → MOD ROUTES → MPE TIMBRE** routes member-channel CC 74 to
filter cutoff. Enable **MPE PITCH** on **PARTS** to use it. Each part
has a signed depth of −2 to +2 octaves, and CC 74 at 64 is neutral.
Timbre affects the entire note stack and stays latched after key-up.
The existing pressure routes can be used alongside it.

Four parameters append for 522 total controls. Patch schema 25 and host
state 27 store the new depths. Earlier patches retain their settings and
open with zero timbre depth.

The Windows VST3 and standalone built successfully. All 28 plug-in and
13 native checks passed. The built VST3 passed centered and bipolar CC 74,
member isolation, sustain, channel reuse, and prior pitch and pressure checks.
The 42 earlier stereo captures, Two Lanterns, and the native reference
phrase matched their previous results exactly.
