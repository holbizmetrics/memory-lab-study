# Memory Lab Study v0.7.0-alpha.1

Preserves the verified white-noise milestone at source commit a069889.
This prerelease tag was added retrospectively to the delivered version.

- WHITE NOISE on OSC adds a separate deterministic pseudorandom stream per voice
  before the existing amplitude envelope and shared voice filter.
- Noise level uses approximately 20 ms target smoothing and defaults to zero.
  Mute saw/pulse for noise alone. The noise and oscillator mix then enters the
  existing per-voice and shared drive stages.
- One appended parameter, 40 controls total. Schema-4 patches; older patch/project
  states load with noise off, preserving their supported oscillator/drive settings.

Native CTest 5/5, plugin CTest 4/4, actual built/installed VST3 validation and
normal/compact editor inspection passed. The default phrase remained byte-identical.
The previous 0.6 installation was retained as a verified local backup.

Listening status remains open: Holger approved the isolated study examples but
subsequently found the integrated noise could affect the sound undesirably.
A later diagnostic reproduced all six study renders exactly at matched settings;
that does not establish approval of the integrated sound or diagnose his patch.
Separate/parallel noise filtering is not implemented, and 0.8 does not change this
noise routing.

An original instrument study, not a measured hardware emulation. Full FL automation
recording/undo/project reload remains unverified. Source-only prerelease without
binary assets; distribution licensing remains to be selected.
