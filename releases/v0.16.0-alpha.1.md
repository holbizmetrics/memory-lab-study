# Memory Lab Study v0.16.0-alpha.1

ENVELOPES now has ENV 3 and ENV 4 alongside the existing amplitude and filter
contours. Each new per-voice dAHDSR contour has six stage controls and independent
bipolar pitch and cutoff depths, with a curve preview. Stage settings latch on
note-on; route depths are smoothed. Both sources can run together and default
to no modulation. Their release never extends the existing amplitude-controlled
voice lifetime. Broader modulation routing remains the next milestone.

Compatibility: the first 76 host IDs/order remain unchanged; 16 controls append,
92 total. Patch schema 11 and host-state version 13 store the new values. Old
patches (schemas 1-10) and old host states load inactive new routes. Default,
clocked and a local saved two-LFO sound render byte-identically to preserved
earlier captures. Existing starter sounds reset these routes off; Dice protects
their settings. The Windows version resource now updates with the build version.

Validation: Windows VST3 and standalone builds; 13/13 plugin checks (104.36 s),
6/6 native checks (44.98 s), and nine actual VST3 audio fixtures passed. Covered
stage boundaries, early release, zero durations, stage latching, both independent
destinations, combined-source contributions, four sample rates, block partition
parity, sustain, voice lifetime, eight-voice allocation/all-sound-off, patch and
host recall, 92 parameter bindings/gestures and passive editor navigation.
Actual VST3 scan/load/audio/state/release/reload passed. Normal/compact ENV 3/4
snapshots inspected. Fixture peak 0.606819; one eight-note offline capture held
median block time 1006.1 us at 48 kHz / 512 frames. This is not a realtime xrun test.

Holger confirmed 0.15's LFO 3 filter route, LFO 4 pitch route and combined sound,
patch-file restoration and FL-project restoration after restarting FL. New
0.16 envelope musical approval is pending. Full live FL automation/undo and
every modulation combination remain outside these checks. The older project
instance's shorter FL parameter table remains unresolved; a fresh 0.15 instance
exposed the correct table. Do not shift indices or apply mismatched manifests.

This closes the envelope-count gap, not measured hardware equivalence. The synth
is an original Relic-inspired study with further oscillator/filter/routing and
four-part architecture work remaining. Source-only prerelease; no binary assets
are distributed until licensing is selected.
