# Memory Lab Study v0.29.0-alpha.1

**FILTER → MODERN → EXTENDED LP BW** lets the bandwidth control shape
LP2, LP3, LP4 and the blends that include them. Narrower bandwidth can
emphasize the low-pass knee. Wider bandwidth damps it. One octave is
neutral for the low-pass response. Pure BP4 retains its existing response.

The toggle is per part and defaults off. Four new controls append after
the previous 526. Patch schema 27 and host state 29 store the toggle.
Older patches and projects start in Legacy even when the previous preset
used a wide or narrow bandwidth. Copy Part carries the toggle with the sound.

The Windows VST3 and standalone built successfully. The native filter
impulse and display checks agree at four sample rates. Compiled VST3
captures confirm the LP2, LP3 and LP4 response, Legacy and BP4 isolation,
neutral bandwidth, and state recall. The native reference phrase,
42 earlier VST3 captures, and Two Lanterns matched exactly.
Holger confirmed 0.28 vibrato fade and project recall in FL Studio.
The 0.29 listening and project recall checks are pending.

The damping curve is a Memory Lab design. Relic's exact response remains
unknown. This prerelease publishes source only.
