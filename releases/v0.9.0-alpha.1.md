# Memory Lab Study v0.9.0-alpha.1

MOTION adds an LFO SHAPE control: sine, triangle, rising saw and 50% pulse.
The selected per-voice, note-retriggered LFO feeds the existing pitch, pulse-width
and cutoff modulation routes. The one-second preview follows the selected shape.
The duplicated MEMORY knob on MOTION gives its position to SHAPE; memory depth
remains on VOICE, AMPLITUDE and DRIVE. Rate and modulation depths are unchanged.

Compatibility: all existing 41 host parameter IDs and indices remain intact.
`lfoShape` appends at index 41, bringing the total to 42. Patch schema 6 saves the
shape; schemas 1–5 and legacy host states restore sine even after another shape
was selected. Older builds cannot read schema 6. Default audio and a nonzero
sine/filter-modulation fixture are byte-identical to verified 0.8 alpha 2 in
actual VST3 captures. Drive, filters, oscillator mix and noise routing are unchanged.

Validation: Windows VST3 and standalone built. All six plugin CTest checks passed:
wrapper/audio/MIDI, automation ID/order/gesture checks, tab isolation, patch-file
roundtrip/migration/rejection, motion waveform/audio/state checks, and isolated
editor lifecycle. Motion checks include waveform range/polarity/period, four
sample rates (44.1/48/96/192 kHz), exact 127/512 block partition parity and
zero-depth neutrality for every shape. Actual VST3 scan, instantiate, MIDI/arp,
state, release and 44.1 kHz reload passed. Triangle/pulse editor snapshots were
visually inspected. Four controlled actual-plugin listening examples are generated
by `plugin/study-motion-shapes.py` into `outputs/motion-shapes-study-1/`.

Listening status: technical checks passed; Holger's musical approval of the new
shapes is pending. Earlier provisional acceptance of 0.8 does not imply approval
of these new modulation sounds. No hardware Relic equivalence is claimed.

Remaining limits: one LFO per voice; no tempo sync, free-running mode, selectable
pulse duty or four-LFO modulation matrix. Saw/pulse intentionally jump; changing
shape on a held note can also cause a modulation jump. No smoothing/crossfade of
the waveform switch is claimed. Full FL automation recording/undo/project-reload
verification and live remembered-folder testing remain open. Local installation
requires FL/standalone closed and a hash-verified backup. Source-only prerelease,
without binary assets, pending distribution licensing.
