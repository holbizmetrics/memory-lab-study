# Memory Lab Study v0.14.0-alpha.1

MOTION gains an independent second per-voice LFO. LFO 1 / CLOCK 1 retain existing
controls; LFO 2 / CLOCK 2 add own rate, sine/triangle/saw/pulse shape, pitch/PWM/
cutoff depths, tempo sync/division, retrigger/free run and fallback BPM. Sources
add at the existing pitch, pulse-width and cutoff destinations. All second-source
depths default to zero. This milestone adds two-source modulation, not four LFOs
or a full routing matrix. See plugin/LFO2.md for behaviour and listening recipe.

Includes 0.13's eight starting sounds/category browser, explicit LOAD and one-step
UNDO LOAD. Loading preserves output and bypasses both drives. Starting sounds
initialize LFO 2 inactive. Dice preserves all LFO 2 settings regardless of its
motion lock; it still varies LFO 1 only. INIT resets both sources. Local route
map roadmap/index.html and MILESTONES.md now identify the second-LFO checkpoint
and the required musical review before any four-LFO expansion.

Compatibility: existing 49 host parameter IDs/order preserved; nine new controls
append at indices 49-57, 58 total. Schema-9 files require 0.14 or later. Schemas
1-8 and legacy host states restore inactive LFO 2 defaults even after edits in
the same instance. Host-state version 11. Existing default sound and migrated
schema-7 clocked VST3 audio are byte-identical to verified 0.12/0.13 captures.
The installed update goes directly from verified 0.12 to 0.14 with backup;
0.13 has its own preserved source tag/prerelease and local verified bundle.

Validation: Windows VST3/standalone built; all 11 plugin CTest checks and all six
native checks passed. New coverage includes each of three LFO 2 destinations,
four shapes at 44.1/48/96/192 kHz, equivalent first/second source response,
two-source block partition parity, six synced divisions, note reset/free-run
through silence, independent host/fallback clocks, old-patch/host migration,
exact rendered bypass after migration, 58 stable automatable controls with
balanced gestures, and 240 passive page switches. Existing preset/patch/Dice/
expression/lifecycle checks pass, including protecting nondefault LFO 2 settings.
The free-run fixture uses a quarter-cycle delay; the original full-cycle delay
could not distinguish advancing from stationary phase. The raw PWM zero-roundtrip
residual (~2.98e-8) uses bounded tolerance plus exact rendered-bypass verification,
consistent with existing wrapper default canonicalization.

Actual VST3 scan/load/MIDI/arp/state/release/reload validation passed. Nine
actual-module fixtures cover clean/inactive parity, isolated LFO routes, combined
sources, sync and eight-note stress. All finite/audible/below full scale in these
fixtures; largest peak 0.608291 at output 0.25. Normal and compact LFO 2/CLOCK 2
editor snapshots inspected. Route-map selection/cursor/navigation and site asset
checks pass in a DOM fixture; actual browser layout/media interaction unverified.

Listening: Holger confirmed 0.12 expression and Dice bypass/Undo. He explicitly
chose to combine 0.13 starting-sound tests with 0.14, then test the second LFO
before further expansion. Both new musical approvals remain pending. Do not
infer them from technical checks or proceed to 0.15 before that review.

Limits: sync is speed-only, not PPQ/bar alignment; free phases are not serialized
and advance only while processed. Discrete shape/clock-mode changes may jump.
Combined modulation reaches existing width/cutoff clamps. No MPE, four-envelope/
four-LFO architecture or faithful Relic hardware match is claimed. Full FL mouse
recording/undo/project-reload, wrapper Randomize/Hybridize and live folder recall
remain separate manual host checks; active crash triage stays parked. Source-only
GitHub prerelease with no binary assets, pending distribution licensing.
