# Memory Lab Study v0.5.0-alpha.1

SAVE/LOAD patch files and optional per-voice drive, installed and auditioned in
FL Studio. Holger approved the drive sound during musical playing on 2026-10-29.
The plugin reports version 0.5.0.

## Features

- SAVE/LOAD buttons preserve all 36 controls in separate `.mlpatch` files.
- A DRIVE page adds 0–24 dB per-voice post-filter clipping before voice mixing
  and the existing shared memory drive. Zero bypasses the new stage exactly.
- Drive changes use 20 ms smoothing, with the first dB fading the stage in.
  A static transfer graph shows the selected clipping response.
- Original 35 host parameter IDs and order are preserved; voiceDrive appends.
- Older host states and schema-1 patches load with voice drive off. New patch
  files use schema 2 and require this build or later.

## Verification

- Native CTest 3/3 and plugin CTest 4/4 passed.
- Actual built and installed VST3 scan, MIDI/audio, drive state recall,
  arp/state/all-off, release and second instantiation checks passed.
- Enabled-drive block partitioning and held eight-note edits at
  44.1/48/96/192 kHz passed; normal and compact editor snapshots inspected.
- Default native audio is byte-identical to the pre-drive baseline.
- The installed 0.4 bundle was backed up and verified before the 0.5 update.

## Limits

Hard clipping is not oversampled and can alias. Use OUTPUT to compensate for
added level; per-voice clipping does not limit the mixed output. This is an
original subtractive instrument study, not a measured hardware emulation.
Envelope stages remain latched at note-on. Existing arpeggiator limits remain.

Full FL automation recording/undo/project recall and native patch-dialog use
inside FL remain unverified. The earlier FL reload crash investigation stays
parked pending recurrence; isolated lifecycle tests do not establish FL safety.

Source-only prerelease without binary assets. Binary distribution licensing
remains to be selected. See plugin/README.md for build instructions and the
pinned JUCE dependency. Earlier tags remain unchanged.
