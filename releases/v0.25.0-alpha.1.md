envelope and amplitude velocity act after filtering and before Voice Drive.
Legacy keeps them before the filter. Each note uses the mode selected at
trigger time through release. The same filter and clipping code serve both
paths. Shared Memory Drive stays after the voice mix.

order and ranges are unchanged. Patch schema 20 and project state 22 default
older sounds to Legacy. INIT and starter sounds reset the mode, part copy
includes it, and Dice preserves it.

for 0.24.

and the native reference phrase byte-for-byte. Eight new actual VST3
