# Memory Lab Study v0.22.0-alpha.1

Optional CURVE and TIME SCALE controls on all four envelope pages, per part.
LEGACY/x1 preserves the approved contours. CURVED uses a rising-target attack
and shaped decay/release; TIME SCALE extends nonzero stages to 0.1 ms–100 s,
with zero still immediate. The preview shows effective timing. Settings latch
on the next note. Duplicate drive/route knobs move off the envelope pages;
their original parameters remain accessible on DRIVE/ROUTES and other pages.

total. Schema 17 / host state 19 migrate old sounds to Legacy/x1. INIT, starter
loading and part copying include the options; Dice preserves them. Host tail
report increases to 101 seconds for long releases. No default sound change.

UI helper and rerunning its failed check; the other 19 passed the full run.
9/9 native checks pass. Formula/range/stage/latching and four-rate release,
multipart parity, migrations, copy/starter isolation and bindings are covered.
Forty-five actual 0.21 VST3 captures remain byte-identical. Eleven new module
fixtures cover Legacy/Curved on all envelopes, short/long timing and combined
parts (peak 0.060171 at their settings). The native reference phrase remains
exact. Actual VST3 scan/load/MIDI/arp/state/release/reload passes. Normal and
compact envelope previews inspected. Local HTML references and route navigation
checked; the public page's browser layout was not rechecked.
Holger's new-envelope musical and live recall approval is pending. Curved mode

scale and apply the documented bounds. Realtime CPU/dropout, aliasing, full FL
automation recording/undo and long-session checks remain open.
