# Memory Lab Study v0.8.0-alpha.2

Usability update following Holger's drive-control and Classic Profile feedback.

- CLASSIC PROFILE is disabled and dimmed in LP4, BP4 and Blend. Its retained
  value becomes editable again in Classic; host family changes update the UI.
- Drive help explicitly describes intentional per-voice clipping and independent
  shared saturation. Zero bypasses the respective drive effect; OUTPUT is level.
- Successful patch saves/loads remember their folder across editor/application
  restarts. Cancelled or rejected operations do not change the preference;
  unavailable folders fall back to Documents. Local UI preference only.
- Retained reproducible version, timing, held-window and compensation-study tools
  and the live FPSDK recall evidence in the investigation notes.

Compatibility: unchanged production DSP, default sound, 41 host parameter IDs and
order, schema-5 patch format and older-patch migration. No new sound parameters.
The existing drive algorithms and noise routing remain as before.

Validation: built VST3/standalone; actual VST3 scan, instantiate, MIDI/state,
release and reload checks passed. Default and saved Classic/MAX-noise raw audio
are byte-identical to the prior verified 0.8 fixtures. Profile enable-state
updates, no editor/tab parameter writes and real on-disk folder reopen checks
passed alongside patch/automation/lifecycle checks. Native response tests were
previously expanded to 90 impulse / 630 complex comparisons and passed.
Normal Blend and compact Drive editor snapshots were visually inspected.

Listening status: Holger provisionally accepts current playback with drives off
and accepted voice drive down/shared drive enabled; he clarified that he had not
expected intentional distortion from VOICE DRIVE. This is not a measured DSP
repair, universal listening approval or a claim of hardware Relic equivalence.

Remaining limits: actual FL native-dialog folder persistence still needs a live
check after local installation. Full FL automation recording/undo/project reload
is not established. This build is prepared and verified separately; the running
FL installation was not overwritten. Local update requires FL and the standalone
closed, with backup/hash verification. Source-only prerelease, no binary assets;
distribution licensing remains undecided.
