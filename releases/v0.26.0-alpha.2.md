# Memory Lab Study v0.26.0-alpha.2

**VOICE → EXPRESSION → UNISON** stacks one, two or four voices per note in
the selected part. **UNISON DETUNE** spreads the pitches around the played
note, and **STEREO SPREAD** positions the voices across the stereo output.
Stacks share the existing eight-voice budget and stay within the part's
reservation. Changing the count stops the edited part's held notes.

The first 505 parameter IDs, order and ranges are preserved. Eight controls
append, bringing the total to 513. Patch schema 22 and host state 24 store both
settings for every part. Older patches and projects use one voice per note
and keep their existing stereo spread. Copy Part includes both settings.

The Windows VST3 and standalone built successfully. All 25 plugin checks
and 13 native checks passed, including whole-stack releases, sustain,
stealing, part limits, gain scaling and recall. The native reference phrase
stayed exact, and 38 earlier VST3 captures matched in both channels. Four
new VST3 captures exercised one voice, two and four detuned voices, and four
detuned voices with stereo spread.

Holger heard the stereo spread in FL Studio on alpha.1. The alpha.2 unison
listening and FL project-recall checks are pending. Eight-voice unison and
additional output buses remain open. This is a source-only prerelease.
