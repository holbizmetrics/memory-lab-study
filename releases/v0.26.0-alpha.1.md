# Memory Lab Study v0.26.0-alpha.1

**VOICE → EXPRESSION → STEREO SPREAD** places voices at different positions
across the main stereo output. Each part has its own depth. The position
follows the voice slot through sustain and release, and changing depth smoothly
adjusts held voices. A mono bus uses the original centered signal. Stereo
spread uses separate shared-drive processing for the two wide signals, so a
driven stereo fold can differ from the mono bus.

The first 501 parameter IDs, order and ranges are preserved. Four parameters
append, bringing the total to 505. Older patches and project states open at
0% spread. Patch schema 21 and host state 23 preserve the new setting.
INIT and starter sounds reset it, Copy Part includes it, and Dice preserves it.

Holger confirmed the clean and driven amp-position difference in 0.25 plus
older patch loading.

The Windows VST3 and standalone built successfully. All 24 plugin and
12 native checks passed. The native reference phrase stayed exact. All 35
earlier VST3 captures matched byte-for-byte in both channels. Three new chord
captures verified center, wide, and wide with drive; the clean stereo fold
matched center within float rounding. Tests covered held changes, mono bus
fallback, part layers, block parity and panic. The actual VST3 passed
scan/load/MIDI/state/reload, and both editor preview sizes were inspected.

The 0.26 FL listening round is pending. This first 0.26
milestone covers stereo spread. Unison, additional output buses and the exact
hardware pan policy remain open. Source-only prerelease.
