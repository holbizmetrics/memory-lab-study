FILTER / MODERN adds an opt-in continuous BP4 → XF4 → LP2 → LP3 → LP4 profile
and band-pass bandwidth control. Static response tracks the topology; inactive
controls dim. Changes/crossfade smooth over 20 ms. Existing cutoff modulation,
expression, envelopes, noise and drives apply. FAMILIES retains the old choices.

Compatibility: first 103 IDs/names/order preserved; three append, 106 total.
Modern defaults off. Schema 14 / host state 16 store additions; old patches and
states migrate with Modern off, profile 0.5 and BW 1. INIT/starter sounds keep
the approved foundation; DICE protects additions. Alpha.2 endpoint fix remains.
No legacy gain/routing changes. Old plugins cannot load schema 14 patches.

Validation: Windows VST3/standalone build; 16/16 plugin and 7/7 native suites.
Four-rate reference/impulse/display checks, Q/BW extremes, five anchors,
eight-voice/Q8 drive off/on, automated block parity, all-off, migration,
patch/host recall, automation/bindings and passive navigation pass.

fixtures peak 0.163812. Neither is universal headroom. Sixteen legacy
family/drive/noise captures match installed alpha.2 byte-for-byte. Eight waveform
fixtures and five earlier default/motion/envelope/routing/saved recordings remain
unchanged. Four Wave Blend passes real file-loader recall. Actual module
scan/load/audio/state/release/reload and normal/compact UI pass. Local HTML
references checked; browser layout not rechecked.

Holger confirmed prior width/tuning and alpha.2 patch/FL project recall.
New modern-filter listening and live recall remain pending. This is a behavioral
approximation: hardware coefficients, sweep/BW law and gain calibration are not
established. High resonance and intentional drives can distort. Profile/BW
modulation, hard sync, oscillator-1 PWM routing, four-part allocation, complete
realtime CPU/aliasing and FL automation/undo validation remain open.

Source-only prerelease without binary assets pending licensing. Installation
requires closed FL/standalone and a verified backup of the previous bundle.
