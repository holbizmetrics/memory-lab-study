# Memory Lab Study v0.27.0-alpha.1

Enable **MPE PITCH** on **PARTS** to bend one note and its unison voices
independently. The fixed lower zone uses MIDI channel 1 for the manager
wheel at ±2 semitones and channels 2–16 for member bends at ±48 semitones.
The manager pedal and panic controls apply across the zone. Lifted notes
keep their member bend through sustain and release.

MPE pitch is off by default. One new control appends to the 513 existing
host controls. Patches and projects retain the selection with patch schema
23 and host state 25. Earlier saves open with their original MIDI behavior.

The Windows VST3 and standalone built successfully. All 26 plug-in and
13 native checks passed. The built VST3 passed measured MIDI tests for
initial and held pitch bends, unison stacks, the manager wheel and pedal,
channel reuse, stealing and panic. All 42 previous VST3 captures and the
Two Lanterns patch matched in both channels. The native reference stayed exact.
