# Memory Lab Study v0.11.0-alpha.2

PATCH DICE gains an optional BYPASS DRIVES checkbox. It is off by default.
When checked, the next roll sets VOICE DRIVE and SHARED DRIVE to zero. Checking
alone changes no sound controls. Unchecked preserves the previous dice behaviour
and current drive values. UNDO ROLL restores the full prior patch, including drives.

With every section locked, rolling can still bypass active drives; only those
drive controls change. Once both are zero, an all-locked roll becomes a no-op and
retains its undo history. Output, memory/recovery, arp, oscillator phase reset,
fallback BPM and locked sound sections remain protected. The checkbox survives
editor close/reopen in the same instance, alongside locks; it is not stored in
patches/projects or exposed as a host parameter. Saved rolled patches contain
the resulting zero drive values normally.

Compatibility: unchanged DSP, default sound, 46 host IDs/order and schema-7 patch
format. No migration change or new sound parameter. The interface badge identifies
this follow-up as STUDY / 0.11 a2.

Validation: VST3/standalone built; all eight plugin CTest checks passed, including
32 lock/bypass combinations, protected-control no-writes, passive checkbox,
drive-only all-locked rolls, no-op history, undo restoring drives and session
persistence. Existing seeded, patch, automation, clock, lifecycle and 32 eight-voice
audio checks pass. Actual VST3 scan/load/MIDI/arp/state/release/reload passed.
Default and original seeded-dice fixture audio are byte-identical to their prior
verified captures. Normal/compact checked-checkbox screenshots were inspected.

Listening status: Holger reports loving 0.11's dice sounds and approved the added
option's proposed behaviour. Live confirmation of the new checkbox remains pending;
technical checks do not substitute for that interaction/listening check.

Limits: bypasses the two intentional drive stages, not every possible source of
clipping or distortion. Existing smoothing applies; play new notes after rolling
to hear the new envelopes. Preserved output/high-resonance or other locked
settings and host processing can still affect level or distort. It is not a
limiter or loudness normalizer. Conflicting host automation can override rolled
values. Full FL automation/undo/project-reload and live folder persistence remain
open. Installation requires closed hosts and verified backup. Source-only
prerelease with no binary assets, pending distribution licensing.
