# Memory Lab Study v0.6.0-alpha.1

Preserves the verified oscillator-control milestone at source commit c099311.
This prerelease tag was added retrospectively to the delivered version.

- OSC page with independent saw/pulse levels and oscillator 2 intervals from
  -24 to +24 semitones, alongside fine detuning and pulse-width controls.

  held-note interval changes give a short glide without resetting oscillator phase.
- Original mix/default sound preserved. Three appended parameters retain the
  original 36 host mappings, for 39 controls total.
- Schema-3 patch files; older patch/project states restore the original mix and
  zero interval while preserving supported drive settings.

normal/compact editor inspection passed. The default phrase remained byte-identical.
