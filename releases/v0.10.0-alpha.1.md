# Memory Lab Study v0.10.0-alpha.1

MOTION gains a CLOCK subpage with tempo sync, six rhythmic divisions, independent
fallback BPM and LFO note retrigger/free-running mode. Sync off keeps the existing
smoothed Hz control. Sync on follows valid host tempo, falling back to its own
20–400 BPM setting. Divisions are quarter, eighth, sixteenth, 32nd, eighth triplet
and sixteenth triplet. The arpeggiator's clock controls remain independent.
The preview reports effective frequency, tempo source and phase mode; inactive
rate/division controls are dimmed. Retrigger off lets notes join a shared clock
that advances through silence while audio is processed.

INIT, available beside SAVE/LOAD on every page, restores factory sound and arp
controls, including drive/output/LFO defaults. It replaces unsaved control edits,
leaves the patch folder alone and does not restart held notes. Save first to keep
edits; play new notes after initialization. Host automation can override controls.

Compatibility: the original 42 host IDs and indices are unchanged. Four controls
append at indices 42–45: lfoSync, lfoDivision, lfoRetrigger and lfoBpm. Schema 7
saves all 46 controls; schemas 1–6 and old host states restore unsynced,
note-retriggered defaults. Saved free rates and waveform choices remain intact.
Older builds cannot read schema 7. Actual VST3 default audio and a legacy active
sine-modulation fixture remain byte-identical to verified earlier builds.

Validation: VST3 and standalone built; all seven plugin CTest checks passed,
including waveform/clock timing at 44.1/48/96/192 kHz, six divisions, exact block
partition parity, retrigger independence from prior silence, free-phase advance,
host/fallback/invalid-tempo handling, arp clock independence, stable automation
IDs/gestures, patch/host migration, 144 page switches without parameter writes,
INIT equality with a fresh instrument, and isolated editor lifecycle. Actual VST3
scan/load/MIDI/arp/state/release/reload passed. Equivalent quarter/120 BPM and
eighth/60 BPM captures are byte-identical; free-run captures differ as expected.
Normal and compact CLOCK snapshots were visually inspected. Listening examples:
`outputs/motion-clock-study-1/index.html`, generated by study-motion-clock.py.

Listening: Holger confirmed 0.9's waveforms work in FL and sound cool. Approval
of 0.10's new timing controls remains pending; technical checks are not musical
approval or hardware Relic equivalence.

Limits: BPM sync controls speed, not PPQ/bar alignment. Free phase resets on
engine prepare/reset, does not follow transport seeks/start/stop, and is not
stored in patches. Disabling audio processing pauses it. Timing/shape switches
on held notes may jump; tempo changes apply at block boundaries with immediate
synced speed changes. Still one LFO mode/shape shared across the instrument, with
per-note phase in retrigger mode; no modulation matrix or multiple independent
LFOs. Full FL automation undo/project-reload and live remembered-folder checks
remain open. Local installation requires closed hosts and verified backup.
Source-only prerelease, no binary assets, pending distribution licensing.

The requested dice/patch randomizer is recorded for a later milestone and is not
implemented here.
