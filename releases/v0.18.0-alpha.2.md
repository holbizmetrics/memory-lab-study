# Memory Lab Study v0.18.0-alpha.2

Fix patch recall rejecting valid range endpoints, including OSC 1 WIDTH at
0.1 in Holger's Four Wave Blend patch. XML decimal formatting rounded the
saved float slightly below its exact double-precision endpoint. The loader
now allows only double-formatting error at the boundaries and clamps that
rounding residue. This is far smaller than a float ULP or parameter step.
Complete validation still happens before any controls change.

Also shorten and reposition the VOICE contextual hint so it clears DICE
and SOUNDS at normal and compact sizes.

Compatibility: no DSP, default sound, parameter IDs/order, patch schema (13)
or host-state version (15) changes. All 103 controls remain compatible.
Existing affected files load without editing or resaving them.

Validation: the new endpoint save/load regression failed before the fix.
All controls now roundtrip at both endpoints; the next representable float
outside either boundary is rejected without partial edits. Holger's original
file passes the real file loader and a subsequent recall roundtrip, read-only.
Windows VST3/standalone build and wrapper smoke checks pass. Six targeted
suites cover patch files, automation, tabs, presets, routes and oscillator mix.
Eight actual VST3 fixtures pass; default, clock, active envelopes, active
routing and saved two-LFO sound remain byte-identical. Normal/compact hint
previews inspected.

Holger confirmed oscillator-1 pulse width tone differences and oscillator-2
saw octave tuning in alpha.1. His blend patch recall failed and is not counted
as approved; live recall with this fix remains pending. This release does not
claim hardware sound equivalence or complete FL automation/undo verification.
Modern filter profile/bandwidth work remains separate.

Source-only prerelease, without binary assets pending distribution licensing.
Local installation is separate and requires closed FL/standalone plus a
verified backup of the previous bundle.
