# Memory Lab Study v0.23.0-alpha.1

FILTER / MOD ROUTES adds ENV 3 and LFO 1 modulation of filter profile and
resonance, independently per part. Signed profile offsets clamp the result
to 0…1; additive Q offsets clamp to 0.5…8. Profile routes work with Classic or
Modern and are inactive in legacy LP4/BP4/Blend when Modern is off. Resonance
routes work in all families. The new page exposes base profile/Q/cutoff and
clearly labels its graph as a base response, not per-voice animated modulation.

Existing source settings apply: LFO polarity/shape/clock and ENV 3 contour/time.
Depths affect held notes with 20 ms smoothing; intentional source steps remain.
High Q can boost levels and drive saturation; bounds do not equal loudness
compensation. This is a bounded explicit routing step, not a general matrix.

Compatibility: all new depths default off. First 457 IDs/order/ranges remain;
16 append, totaling 473. Schema 18 / state 20 migrate older sounds to inactive
routes, retaining prior envelope/polarity settings. INIT/starters/copy include
routes; Dice preserves them. Existing signal path and filter gain laws remain.

Technical validation: Windows VST3/standalone build, 21/21 plugin CTest and
9/9 native CTest pass. Independent sign/sum/clamp references, appended IDs,
legacy migration, recall/copy/starter/Dice isolation, Classic/Modern source
effects, unsupported-family profile bypass, Q routes across families and UI
enabled/selected-part binding checks pass. Four-rate multipart held extreme
depth edits are block-exact and finite with fixture headroom. Fifty-six actual
0.22 VST3 recordings remain byte-identical; 13 new module fixtures pass (peak
0.022566 at their settings). The native reference phrase remains exact. Actual
module scan/load/MIDI/arp/state/release/reload passes. Normal/compact active and
inactive route previews inspected; HTML references and route navigation checked.
The public page's browser layout was not rechecked. Holger's 0.22
amplitude curve/time-scale and patch/project recall round is approved; musical
approval of these new routes remains pending. Full FL automation recording/undo,
realtime/dropout, aliasing and hardware-fidelity checks remain open. Modulator
level routing, MPE and extended low-pass bandwidth remain separate milestones.

Source-only prerelease without binary assets pending distribution licensing.
Installation requires closed FL/standalone and a verified 0.22 backup.
