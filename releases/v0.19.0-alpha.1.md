# Memory Lab Study v0.19.0-alpha.1

PARTS connects four independently editable sounds to one eight-voice budget.
Choose Single (8), 2-layer (4+4), 2-way split (4+4) or 4-layer (2+2+2+2).
Each part has omni/specific MIDI input, the existing sound pages and output,
starter-sound loading, Dice and Copy Part 1. Header and output label identify
the selected part. SAVE/LOAD keep the complete setup; INIT resets all parts.
ARP remains global; routing edits silence held voices and reset its sequence.

Compatibility: first 106 IDs/names/order preserved; 99 sound controls append
for each additional part, then six routing controls, 409 total. Patch schema
15 / host state 17 migrate older files to Single/Part 1 with other parts inactive.
Old sound arithmetic and the patch-endpoint repair remain. New schema files
require this version. Additional parts default to bypassed drives. Their noise
streams are distinct, and newly activated parts prime stored controls.

Validation: Windows VST3/standalone builds; 17/17 plugin and 9/9 native suites.
Four-rate routing/voice-cap/panic/reprepare checks, old/new patch/host recall,
409 IDs and selected-part edit/preset/dice/copy/undo isolation pass. Native
single-part audio matches the old engine exactly; layers match independent
reference sums and block partitions. Eight actual VST3 part fixtures pass
(peak 0.069244 at their settings). Twenty-one legacy/modern captures match
installed alpha.3 byte-for-byte; eight waveform fixtures and five earlier
default/motion/envelope/routing/saved recordings remain unchanged. Actual
module scan/load/audio/state/release/reload and original Four Wave Blend
loading pass. Normal/compact UI inspected. HTML references checked; the web
page's browser layout was not rechecked.

Holger approved the 0.18 modern-filter sweep, bandwidth, inactive controls and
patch/FL project recall. New part musical/UI/FL recall approval is pending.
Fixed reservations, one global arp, additive part output and per-part drives
are deliberate first-stage choices. Custom reservations, voice borrowing,
four-way splits, per-part transpose/arp, separate outputs, complete realtime
CPU/dropout/aliasing and FL automation/undo verification remain open. No
hardware sound-equivalence claim. Use a fresh instance for the expanded table;
never shift a mismatched host parameter manifest.

Source-only prerelease without binary assets pending distribution licensing.
Installation requires closed FL/standalone and a verified alpha.3 backup.
