# Memory Lab Study v0.24.0-alpha.1

**OSC → OSC 1 PWM** adds independent pulse-width modulation for oscillator 1.
Each part has six signed depths (LFO 1–4 and ENV 3–4), plus access to the
existing base width and pulse level. The source timing and polarity still come
from their own pages. Width offsets sum per voice and clamp to 0.1–0.9.

The first 473 parameter IDs, positions and ranges are unchanged. The 24 new
depths append, bringing the total to 497. Patch schema 19 and host state 21
load older sounds with every new depth at zero. Existing width modulation
keeps its OSC 2 destination. Copy Part includes the new depths, INIT and
starter sounds reset them, and Dice keeps them.

Technical checks and listening approval are tracked separately. The 0.23
filter routes passed Holger's individual listening checks in FL Studio.
The Windows VST3 and standalone built successfully. All 22 plugin checks and
10 native checks passed, including schema-18 migration, host recall, editor
part isolation, held depth changes at four sample rates, and a 3,675 Hz
oscillator-bank sine PWM spectral check. All 13 existing 0.23 filter-route
VST3 recordings stayed byte-for-byte identical. Fourteen new actual VST3
captures checked the six sources and OSC 2 isolation. The native reference
phrase stayed exact. The actual VST3 passed scan, load, MIDI, state and reload
checks. Both editor preview sizes were inspected.

0.24 musical approval and live host automation are pending. The production
Relic's full modulation scale, oscillator sync behavior and cross-modulation
remain open. This is a source-only prerelease.
