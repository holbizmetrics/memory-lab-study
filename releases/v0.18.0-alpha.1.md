# Memory Lab Study v0.18.0-alpha.1

OSC / MIX adds oscillator 1 pulse, oscillator 2 saw, and a separate static
oscillator-1 pulse width. Both saw and pulse can now be mixed from each of the
two existing phase/pitch cores. OSC / TUNING retains the previous controls.
Five source bars show all four waveforms and noise. Both added levels default
zero; older sounds keep their original oscillator-1 saw and oscillator-2 pulse.
Oscillator 2 saw follows its existing interval/detune; oscillator 1 width does
not affect oscillator 2. Existing PWM modulation remains oscillator-2-only.

Compatibility: first 100 host IDs/names/order retained; three controls append,
103 total. Patch schema 13 and host state 15 store the new controls; schemas
1-12 migrate with added levels off and oscillator-1 width at 0.5. Levels/width
smooth over 20 ms; let muted sources settle before isolation checks. INIT and
starter sounds reset new sources off; Dice protects the added fields. More
sources can raise level; no automatic normalisation changes older sounds.

Validation: Windows VST3/standalone builds; 15/15 plugin suites (100.05 s),
6/6 native suites (41.97 s). New solo/combined waveforms, separate width/tuning,
four sample rates, block parity, mute/release, held eight-note edits/all-off,
schema-12 and host recall, 103 bindings/gestures and 384 passive page changes
pass. A source-isolation test initially included the original source fade-out;
it was corrected to settle smoothed controls before the fresh note. Eight actual
VST3 fixtures pass (peak 0.366584 at fixture settings). Default, clocked, active
envelopes, active routing and a local saved two-LFO sound render byte-identically
to preserved recordings. Actual VST3 scan/load/audio/state/release/reload passed;
normal/compact mixer UI inspected; PE/plugin versions are 0.18.0.

Holger confirmed tested 0.17 routes, auto-load/manual selection, patch recall,
FL restart/project recall and the remembered auto-load preference. New 0.18
waveform listening/recall approval is pending. This is the first oscillator
step of the 0.18 series: modern filter profile/bandwidth work remains separate.
Hard sync, oscillator-1 PWM routing, full independent modulation, four-part
allocation and measured SEM/hardware matching remain unimplemented gaps.
Full live FL automation/undo and realtime dropout testing remain open. Use a
fresh instance for host parameter inspection; never shift a mismatched table.

Source-only prerelease; no binary assets until distribution licensing is chosen.
Installation is tracked separately and requires FL/standalone closed plus a
verified backup of the prior bundle.
