# Memory Lab Study v0.4.0-alpha.1

First tagged alpha milestone: editable envelopes and an optional arpeggiator for
the original eight-voice subtractive synth study. The plug-in reports version
0.4.0; the alpha suffix identifies this source milestone's prerelease status.

## Added

- Separate amplitude and filter Delay/Attack/Hold/Decay/Sustain/Release envelopes,
  with contextual controls and curve previews. Stages latch at note-on.
- ARP page with host/internal tempo, six straight/triplet rates, Up/Down/Up-Down,
  one to three octave layers, gate length and a rhythm preview.
- Sustain-aware held-chord handling, channel-specific all-off and transport-stop
  cleanup. ARP defaults off, including when loading older patches.
- Legacy preset migration preserves existing parameter IDs and supplies the
  original defaults for missing envelope controls.

## Verification

- Native envelope checks: three sample rates, stage timing, zero stages,
  release during attack, note-on latching and block partition agreement.
- Native arp checks: 54 order/rate/sample-rate cases, fractional timing, gate,
  sustain, channel isolation, note-range limits and tested render allocations.
- Wrapper checks: default/native audio parity, MIDI timing/controllers, preset
  recall/migration, arp block agreement and host/internal/fallback tempo.
- Five editor pages and attachments, arp on-screen keyboard audio, and normal /
  compact snapshots checked; arp layouts visually inspected.
- Installed Windows x64 VST3: scan, instantiate, MIDI/arp audio, state recall,
  all-off/release silence and reload checks passed.

Holger confirmed musical use in FL Studio, saved a 130 BPM piano-roll project,
and reported extended playing and a pleasing "analog character." These are
listening impressions, not a measured hardware match or a timed soak test.

## Known limits

- An original Relic-inspired partial instrument, not a complete hardware emulation.
- Host sync follows BPM. The first held note starts the pattern immediately;
  PPQ-grid quantization and timeline seek/loop tracking are not implemented.
- No arp latch, swing, random order, step sequencer or generated MIDI output.
- Switching ARP on/off clears notes; re-press held notes afterwards.
- Supported native rates are 44.1–192 kHz. Tests cover selected cases and do not
  establish universal realtime, stability or aliasing guarantees.

## Distribution and recovery

This is a source milestone without downloadable binary assets. JUCE is pinned
to the version/commit in plugin/dependency.json; source/build instructions are in
plugin/README.md. A distribution licence must be selected before binary release.

The local installed 0.3 bundle was preserved at
outputs/installed-backup-0.3.0. Build evidence and previews remain local under
outputs/arp-build-0.4.json and outputs/editor-preview-0.4. These ignored artifacts
are not included in the source archive. The updater is a guarded local 0.3-to-0.4
helper and requires those local build records; it is not a general installer.
