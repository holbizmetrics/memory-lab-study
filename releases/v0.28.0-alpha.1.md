# Memory Lab Study v0.28.0-alpha.1

**MOTION → LFO 1 → ENV 3 FADE** adds per-part envelope control of LFO 1
depth. At 100% the depth follows ENV 3, making it possible to fade in
vibrato, tremolo, filter movement, and pulse-width movement on a held note.
Intermediate values blend the envelope-controlled depth with the original
depth. The LFO continues running at its programmed rate.

Four controls append to the existing 522. Patch schema 26 and host state 28
save the new depths. Older patches and projects open at 0% fade and keep
their existing LFO behavior. Copy Part includes the new depth.

The Windows VST3 and standalone built successfully. All 29 plug-in and
13 native checks passed. Actual VST3 tests confirmed fade bypass, delayed
vibrato and tremolo, partial depth, and LFO 2 isolation. The native reference
phrase, 42 older VST3 captures, and Two Lanterns matched exactly.

Holger approved 0.27 pitch, pressure, and timbre isolation and project
recall in FL Studio. The 0.28 envelope fade still needs its FL listening
and recall checks. This is a source-only prerelease.
